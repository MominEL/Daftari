# Reporting a security problem

Thank you for looking. Daftari is a small project made by one person, and I would much rather hear about a problem than not.

## How to report

Use GitHub's private report: open the **Security** tab of this repository → **Report a vulnerability**. Only I can see it.
Please do not open a public issue for a security problem.

## What helps

- What you did, step by step, and what you expected to happen.
- Your Daftari version (Settings → About) and your system (Windows 10/11, macOS version).
- What an attacker would gain (reading or changing someone's notes, running something, reading a key…).
- If you can, how you think it could be fixed.

## What I will do

I will read every report and answer as soon as I can; this is a one-person project, so please be patient. I will tell you when it is fixed and, if you like, credit you in the release notes. There is no payment for reports.

## Things that are known and by design

- The installers are not signed, so Windows and macOS warn on first launch.
- Notes are plain files in your own folder (so you can back them up), and recordings are not encrypted on disk: anyone with access to your computer account can read them.

Please only test on your own computer and your own data.
